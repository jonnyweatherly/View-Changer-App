# View-Changer-App — working notes

Repo-specific context for Claude.

## How problems get reported

Read `.claude/working-agreement.md` before reporting that something is hard,
blocked, risky or expensive. It replaces those words with six named situations,
each with a default and a rule about whether to interrupt. Two defaults matter
most: **look before estimating** (an unread file is not a hard problem), and
**never silently reduce scope**. That file is generic and identical across
repos — keep it that way, and put project-specific rules here instead.
